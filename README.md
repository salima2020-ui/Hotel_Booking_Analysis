Hotel Booking Demand Analysis

Analysis of hotel booking data to study seasonal demand patterns and cancellation behavior, using pandas for data processing and matplotlib for visualization.

Dataset
File: hotel_bookings.csv
Size: 119,390 rows, 32 columns
Content: Bookings for two hotels (City Hotel and Resort Hotel) in Portugal, arrivals between 2015 and 2017
Source: Hotel Booking Demand dataset (Kaggle)
